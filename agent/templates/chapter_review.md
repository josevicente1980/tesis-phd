# Criterios de evaluacion

- Coherencia con el objetivo general de la tesis.
- Claridad de la estructura interna.
- Solidez conceptual y metodologica.
- Consistencia argumental.
- Calidad de redaccion academica.
- Uso adecuado de fuentes y citas.
- Consistencia terminologica.
- Integracion con tablas, figuras y resultados.
- Calidad de transiciones entre secciones.
- Riesgos de redundancia, vacios o contradicciones.

# Checklist

- [ ] El capitulo tiene un objetivo claro.
- [ ] La estructura es logica y progresiva.
- [ ] Las secciones estan correctamente jerarquizadas.
- [ ] Los conceptos principales estan definidos.
- [ ] La argumentacion es consistente.
- [ ] Las afirmaciones relevantes estan respaldadas por citas o resultados.
- [ ] Las tablas y figuras estan citadas en el texto.
- [ ] Las tablas y figuras aportan evidencia relevante.
- [ ] No hay repeticiones innecesarias.
- [ ] No hay contradicciones con otros capitulos.
- [ ] El estilo es academico y uniforme.
- [ ] La terminologia es consistente.
- [ ] Las conclusiones parciales se derivan del contenido presentado.
- [ ] El capitulo conecta adecuadamente con el anterior y el siguiente.
