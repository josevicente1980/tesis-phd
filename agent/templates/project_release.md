# Criterios de evaluacion

- Completitud del alcance definido para la entrega.
- Estado de compilacion del documento.
- Integridad de capitulos, anexos, preambulo y bibliografia.
- Reproducibilidad de codigo, datos y resultados.
- Calidad editorial minima para la etapa correspondiente.
- Existencia y ubicacion de artefactos finales.
- Consistencia entre fuentes y salidas generadas.
- Registro de cambios relevantes.
- Identificacion de riesgos, pendientes y decisiones abiertas.
- Preparacion para revision academica, tecnica o institucional.
