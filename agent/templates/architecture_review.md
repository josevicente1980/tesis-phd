# Criterios de evaluacion

- Claridad de la estructura general del proyecto.
- Separacion entre fuentes, datos, codigo, estilos, salidas y reportes.
- Coherencia entre configuracion Quarto y organizacion real.
- Reproducibilidad del entorno y del pipeline de datos.
- Mantenibilidad de scripts, capitulos y recursos compartidos.
- Trazabilidad entre datos crudos, datos procesados y resultados.
- Gestion de artefactos generados, caches y salidas.
- Estrategia de compilacion y validacion.
- Riesgos de duplicacion, archivos huerfanos o dependencias ocultas.
- Oportunidades de automatizacion de tareas repetitivas.

# Checklist

- [ ] La estructura de carpetas es clara y consistente.

- [ ] Los scripts R tienen responsabilidades diferenciadas.
- [ ] Los datos crudos y procesados estan separados.
- [ ] Las salidas generadas no se confunden con archivos fuente.
- [ ] Los estilos y recursos graficos estan ubicados en carpetas adecuadas.

- [ ] Hay oportunidades de automatizacion identificadas.
- [ ] Los principales riesgos tecnicos estan documentados.
