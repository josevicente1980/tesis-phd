# Objetivo

Evaluar la calidad, consistencia, completitud y pertinencia de la bibliografia y las citas utilizadas en la tesis, identificando errores, riesgos y acciones concretas de mejora.

# Criterios de evaluacion

- Pertinencia academica de las fuentes citadas.
- Correspondencia entre citas en texto y entradas bibliograficas.
- Completitud de metadatos bibliograficos.
- Consistencia de claves BibTeX.
- Cumplimiento del estilo bibliografico definido.
- Actualidad y relevancia de las fuentes.
- Balance entre literatura clasica, empirica y reciente.
- Ausencia de citas huerfanas o referencias no citadas, cuando aplique.
- Calidad de fuentes primarias, institucionales y metodologicas.
- Riesgos de duplicados, errores de autor, ano, titulo o DOI.

# Checklist

- [ ] Todas las citas del texto tienen entrada en la bibliografia.
- [ ] Las entradas bibliograficas relevantes estan citadas en el manuscrito.
- [ ] No hay claves BibTeX duplicadas.
- [ ] Las claves BibTeX siguen un criterio consistente.
- [ ] Los nombres de autores estan normalizados.
- [ ] Los anos de publicacion son consistentes entre texto y bibliografia.
- [ ] Los titulos estan completos y sin errores evidentes.
- [ ] Las revistas, editoriales o instituciones estan identificadas.
- [ ] Los DOI, URL o identificadores estan presentes cuando corresponde.
- [ ] Las fuentes web incluyen informacion suficiente de acceso o publicacion.
- [ ] El estilo CSL aplicado corresponde a la norma requerida.
- [ ] Las citas respaldan afirmaciones sustantivas del texto.
- [ ] No hay sobrecarga de citas irrelevantes.
- [ ] No hay dependencia excesiva de fuentes secundarias cuando existen fuentes primarias.
