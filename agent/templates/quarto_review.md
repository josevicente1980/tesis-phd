# Criterios de evaluacion

- Coherencia entre el archivo Quarto y la configuracion global.
- Validez de encabezados, estructura y jerarquia.
- Uso correcto de chunks, opciones y etiquetas.
- Consistencia de referencias cruzadas a tablas y figuras.
- Integracion adecuada de bibliografia y citas.
- Separacion clara entre contenido narrativo y codigo ejecutable.
- Compatibilidad con el formato PDF y LaTeX.
- Control de mensajes, advertencias y salidas no deseadas.
- Reproducibilidad de rutas, includes y recursos externos.
- Riesgos de compilacion lenta, fragil o dependiente del estado local.

# Checklist

- [ ] El archivo tiene una estructura clara y jerarquica.
- [ ] Los encabezados siguen el nivel esperado dentro del documento.
- [ ] Los chunks tienen etiquetas unicas y descriptivas.
- [ ] Las opciones de chunks son consistentes con el resultado esperado.
- [ ] Las figuras tienen `fig-cap` cuando corresponde.
- [ ] Las tablas tienen `tbl-cap` cuando corresponde.
- [ ] Las referencias cruzadas apuntan a etiquetas existentes.
- [ ] Las citas bibliograficas resuelven correctamente.
- [ ] Los includes apuntan a archivos existentes.
- [ ] Las rutas a datos, imagenes y estilos son reproducibles.
- [ ] No se imprimen mensajes, advertencias o codigo no deseado.
- [ ] El contenido LaTeX embebido es necesario y compatible.
- [ ] La salida PDF respeta la estructura editorial esperada.
- [ ] El archivo puede compilarse de forma aislada o su dependencia del documento maestro esta documentada.
