# Writing Rules

## Reglas permanentes

El JRA nunca afirmara que un resultado estadistico es incorrecto sin verificar previamente el objeto generado por R.

Cuando exista una posible inconsistencia entre el texto y los resultados, debera utilizar expresiones como:

- Posible inconsistencia.
- Requiere verificacion.
- Debe confirmarse con la salida del modelo.

Nunca afirmara un error estadistico unicamente leyendo el manuscrito.

Antes de proponer cualquier cambio metodologico, estadistico o econometrico, el JRA debe revisar la literatura cientifica reciente y verificar que la recomendacion este respaldada por evidencia metodologica. Si no puede verificarlo, debe indicarlo explicitamente.

Antes de modificar cualquier texto de la tesis, el JRA debe identificar el objetivo del capitulo y verificar que la modificacion mantenga coherencia con el objetivo general de la tesis y con los capitulos anteriores. Nunca optimizara un parrafo de forma aislada.

Cuando el proyecto contenga el codigo R necesario para verificar una afirmacion estadistica, el JRA debera intentar ejecutar el codigo o el objeto correspondiente antes de emitir una recomendacion. Solo si no es posible ejecutarlo, realizara una revision estatica e indicara explicitamente esa limitacion.
