# Estilo oficial de los reportes JRA

Todos los reportes del JRA deberán parecer informes de auditoría científica elaborados por un investigador senior.

El objetivo no es impresionar con cantidad de observaciones, sino producir conclusiones rigurosas, objetivas, reproducibles y útiles para mejorar la investigación.

# Principios generales

Cada observación debe distinguir claramente entre:

- evidencia observada;
- interpretación;
- hipótesis;
- conclusión;
- recomendación.

Nunca deberán mezclarse.

# Estructura obligatoria

Cada hallazgo deberá contener:

1. Evidencia encontrada.
2. Cómo se verificó.
3. Nivel de evidencia.
4. Posible impacto.
5. Recomendación.
6. Prioridad.

# Niveles de evidencia

Todos los hallazgos deberán clasificarse como:

## Evidencia demostrada

Existe verificación reproducible mediante R, Quarto, documentación oficial o resultados observados.

## Evidencia probable

Existen indicios importantes pero aún falta verificar parte del pipeline.

## Hipótesis metodológica

Existe una explicación posible, pero todavía no puede demostrarse.

## ⚪ Evidencia insuficiente

No existe información suficiente para concluir.

# Severidad

Cada observación deberá clasificarse como:

- Crítica
- Alta
- Media
- Baja
- Informativa

La severidad deberá justificarse.

# Prioridad

Cada recomendación deberá indicar:

- Alta
- Media
- Baja

considerando únicamente el impacto sobre la tesis.

# Prohibiciones

Nunca utilizar expresiones como:

- esto está mal;
- error evidente;
- claramente incorrecto;
- definitivamente incorrecto;
- inconsistencia grave;

sin evidencia demostrada.

Preferir expresiones como:

- requiere verificación;
- podría representar;
- la evidencia disponible sugiere;
- es consistente con;
- no puede descartarse;
- se recomienda verificar.

# Uso de la documentación oficial

Cuando un hallazgo se apoye en la documentación oficial deberá indicar explícitamente:

- qué documento fue consultado;
- qué sección fue utilizada;
- cómo esa evidencia sustenta la conclusión.

# Uso de R

Cuando se ejecute código R deberá diferenciar claramente:

- resultado observado;
- interpretación estadística;
- implicación metodológica.

# Calidad de las recomendaciones

Las recomendaciones deberán ser:

- específicas;
- ejecutables;
- justificadas;
- priorizadas.

Nunca recomendar cambios generales sin indicar exactamente:

- qué archivo;
- qué objeto;
- qué variable;
- qué bloque del código;
- por qué.

# Principio de mejora científica

El objetivo de cada reporte es fortalecer la calidad metodológica de la tesis.

No debe buscar producir el mayor número posible de observaciones.

Debe buscar producir las observaciones más útiles y mejor fundamentadas.
