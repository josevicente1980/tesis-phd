# Documentación oficial EDIUS para depósito

Este directorio conserva la normativa y los modelos oficiales utilizados para preparar el depósito de la tesis doctoral.

## Estructura

- `normativa/`: documentos oficiales de EDIUS/USC que establecen requisitos de contenido, formato y depósito.
- `modelos/`: modelos o documentos institucionales que se incorporarán al PDF final (cubierta/antecubierta, portada interna, declaración sobre conflicto de intereses, etc.).

## Regla de trabajo

Los PDF oficiales se conservan sin modificaciones. Cualquier integración en la tesis se hará desde copias o mediante inclusión PDF/LaTeX, manteniendo intactos los originales.

La rama de trabajo para esta fase es `deposito-formal-edius`. `main` permanece como punto estable hasta que todos los requisitos formales hayan sido validados.
